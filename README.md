# Haiqal Yousri: Portfolio

Personal portfolio site for Mohamad Haiqal Bin Yousri, Engineering Systems & Design (SUTD).
It is a static site with plain HTML, CSS and JavaScript and needs no build step. It is hosted on GitHub Pages.

## Structure
```
index.html              main page
assets/css/style.css    styles
assets/js/main.js       menu, image lightbox, scroll animations
assets/img/             project images
assets/video/           ARDUNE demo clip
assets/Haiqal_Resume.pdf
```

## Editing
- Text: edit `index.html` directly. Each project is an `<article class="case">` block.
- Images: drop new files into `assets/img/` and reference them as `assets/img/filename.jpg`.
- Resume: replace `assets/Haiqal_Resume.pdf` with a file of the same name.
